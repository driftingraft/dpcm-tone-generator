=====================================================
  dPCM Tone Generator  -  README (please read first)
=====================================================

A tool for creating dPCM samples (.dmc) for the Nintendo
Entertainment System (NES / Famicom), right from your browser.

(日本語の説明は「お読みください.txt」を参照してください)


-----------------------------------------------------
 Windows
-----------------------------------------------------
 1. Double-click "Start.bat" in this folder.
 2. Your browser opens with the tool.
 3. A console (black) window also opens - that is the
    tool itself. Closing it stops the tool.
 4. To quit: close the console window or press Ctrl+C.

 * No Python installation required (it is bundled here).
 * If Windows shows "Windows protected your PC", click
   "More info" -> "Run anyway".


-----------------------------------------------------
 Mac
-----------------------------------------------------
 1. Right-click "Start.command" -> "Open".
 2. In the confirmation dialog, click "Open".
    (Needed only the first time; afterwards you can
    just double-click it.)
 3. Your browser opens with the tool.
 4. To quit: close the Terminal window or press Ctrl+C.

 * If Python3 is not installed, follow the prompt to
   install the "Command Line Developer Tools" (first
   time only), then run "Start.command" again.


-----------------------------------------------------
 Troubleshooting
-----------------------------------------------------
 * If the browser does not open automatically, open
   this address in your browser:
     http://127.0.0.1:8765/

 * If you see a "port in use" error, close other apps
   and try again.


-----------------------------------------------------
 Language
-----------------------------------------------------
 The interface auto-detects your browser language
 (English / Japanese). You can switch anytime with the
 language button at the top-right corner.
